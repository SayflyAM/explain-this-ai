# ExplainThis UI Mockup

## Project Purpose
This is a very simple static frontend training project for ExplainThis.
The goal is to show a basic interface where a user can:
- enter complex text,
- choose Arabic or English,
- click a button to simplify,
- and view a dummy simplified explanation.

This is only a structural UI test and does not include any real API or NLP processing.

## Technologies Used
- HTML5
- CSS3
- Very basic JavaScript (for button click demo only)

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` (or open it in your browser).

No installation is required.

## Beginner-Level Project Notes
- This mockup is static, so it does not call any backend service.
- The interface is intentionally simple to match trainee-level work.
- The result area shows fixed dummy text when the button is clicked.
- The layout uses a basic centered container and simple old-school colors.
